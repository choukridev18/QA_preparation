# Bug Hunt — Gestionnaire de tâches

## Contexte

Ce module gère une liste de tâches (todos) pour une app interne.
Suite à un refactor rapide, 4 tests ont commencé à échouer.
**Le code dans `src/` est correct et ne doit pas être modifié.**

## Ta mission

1. Lance `pytest tests/ -v`
2. Lis les tracebacks — 1 bug par test
3. Corrige uniquement dans `tests/`
4. Quand tout est vert, dis "j'ai fini"

## Règles

- Ne touche pas à `src/` — seulement `tests/`
- Les 3 tests qui passent sont corrects
